# Keshav Dewan — Portfolio

Multi-page data analytics, BI & AI automation portfolio built with **Astro**, featuring Swiss banknote-inspired color fields, Light/Dark mode, **English / French / German** localization, company & product logos, and 10 detailed project case studies.

- **Live site:** https://keshavdewan.github.io/
- **Full editing, customization & publishing manual:** See [PORTFOLIO_GUIDE.md](./PORTFOLIO_GUIDE.md).

## Quick Commands

```powershell
npm install      # First-time setup
npm run dev      # Local live-reload preview
npm run build    # Verify & build static site into dist/
npm run preview  # Preview production build locally
```
