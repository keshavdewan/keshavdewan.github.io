## Context

Enterprise ERP systems store rich operational, financial, and client data across deeply normalized relational tables. During my Business Intelligence Analyst internship at **Mediasoft Group** in Nyon (Apr 2026 – Sep 2026), non-technical teams needed fast, reliable reporting without exposing sensitive records across organizational boundaries.

## Approach & engineering discipline

1. **Relational extraction & validation:** Extracted, transformed, and validated complex relational ERP datasets using SQL and Power Query, checking referential integrity, nulls, and business-rule edge cases before modeling.
2. **Scalable Fabric semantic models:** Partnered directly with non-technical stakeholders to translate ad-hoc operational questions into reusable Microsoft Fabric semantic models and clean Power BI dashboards.
3. **Security & governance by design:** Implemented Row-Level Security (RLS) and dynamic filtering rules so each user only sees authorized rows while consuming a single governed dataset.
4. **Software-grade BI delivery:** Integrated Microsoft Fabric with Git version control and CI/CD workflows, supported by end-to-end technical documentation for long-term maintainability.

## Results

- Established strict data integrity, governance, and Row-Level Security standards across cross-functional operational reporting workflows.
- Enabled rapid turnaround on ad-hoc analytical requests while keeping core metrics consistent across departments.
- Left behind standardized technical documentation covering semantic model definitions, DAX logic, and deployment steps.
